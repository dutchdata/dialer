# Dialer

AI for phone chores. A personal Mac app: it places calls through the owner's iPhone, either personally or delegated to AI with a typed task.

Page: https://dialer.dutchdata.io

This repository holds the product page, the demo video and the screenshots. The app's code is not published. Personal build, not for sale.

The conversation in the video and screenshots is staged: synthetic voices, a fictional business, invented contacts.
